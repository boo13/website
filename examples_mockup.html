Implementation notes

The demo keeps the canvas sticky and updates the frame only when the scroll position changes enough. Frames are preloaded lazily in small batches so the first interaction is instant and the rest streams in as the user explores.

Sampling Using every 4th frame from the 30fps export keeps motion smooth while holding payload down to ~225 images.
Canvas scaling The canvas redraws on resize and letterboxes the artwork so the original aspect is preserved without stretching.
Graceful loading A queue driven by requestIdleCallback (with fallback) batches downloads so the browser never chokes on hundreds of simultaneous requests.
