YouTube Analytics Collector

Private desktop tool · operated by Randy Counsman · last updated 15 September 2026

This is a private, read-only desktop collector that pulls YouTube Analytics for a channel Randy Counsman is authorized to read. It runs on a personal Google Cloud project and feeds a personal production dashboard.

It is not a public app, not an Every product, and not affiliated branding for Every. Browser consent is completed by Randy as himself.

Access is read-only. The collector may request these Google API scopes:

  • https://www.googleapis.com/auth/youtube.readonly
  • https://www.googleapis.com/auth/yt-analytics.readonly
  • https://www.googleapis.com/auth/yt-analytics-monetary.readonly — only if revenue collection is explicitly opted into

It does not upload videos, moderate comments, change ads or channel settings, manage the Google account, or act as a service account.

Tokens and analytics stay in local private storage on Randy’s own computers. They are not sold, not used for ads, and not shared with a third party.
