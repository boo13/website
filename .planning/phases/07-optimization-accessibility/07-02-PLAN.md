<task type="auto">
  <name>Task 2: Add focus-visible styles and configure Vite chunk splitting</name>
  <files>src/styles/index2.css, vite.config.js</files>
  <action>
  **CSS: Focus-visible styles**

  Add a `:focus-visible` section to `src/styles/index2.css` (near the top, after the reset section). These provide visible focus rings for keyboard navigation without showing them on mouse clicks:

  ```css
  /* =====================================================
     FOCUS VISIBLE - Keyboard Navigation
  ====================================================== */
  a:focus-visible,
  button:focus-visible,
  input:focus-visible,
  select:focus-visible,
  textarea:focus-visible,
  [tabindex]:focus-visible {
      outline: 2px solid var(--color-offwhite);
      outline-offset: 3px;
  }

  /* Dark background sections need visible outline */
  .gallery-card:focus-visible {
      outline: 2px solid var(--color-offwhite);
      outline-offset: 4px;
      border-radius: 8px;
  }

  /* Remove default focus for mouse users (focus-visible handles keyboard) */
  a:focus:not(:focus-visible),
  button:focus:not(:focus-visible) {
      outline: none;
  }
  ```

  Also update the existing `.newsletter-input-group input[type="email"]:focus` rule (around line 518) to use `:focus-visible` instead of `:focus`. Keep the existing styling (border-color change) but switch the pseudo-class.

  **Vite: Vendor chunk splitting**

  Update `vite.config.js` to add manual chunk splitting for vendor libraries. This separates GSAP (~58KB) and GLightbox (~19KB) into their own cached chunks:

  ```javascript
  import { resolve } from 'path';
  import { defineConfig } from 'vite';

  export default defineConfig({
    root: '.',
    publicDir: 'public',
    build: {
      outDir: 'dist',
      rollupOptions: {
        input: {
          main: resolve(import.meta.dirname, 'index.html'),
          index2: resolve(import.meta.dirname, 'index2.html'),
          contact: resolve(import.meta.dirname, 'contact.html'),
          resume: resolve(import.meta.dirname, 'resume.html'),
          examplesMockup: resolve(import.meta.dirname, 'examples_mockup.html'),
          sandbox: resolve(import.meta.dirname, 'sandbox.html'),
          wyatt: resolve(import.meta.dirname, 'case_study_wyatt.html')
        },
        output: {
          manualChunks: {
            gsap: ['gsap', 'gsap/ScrollTrigger', 'gsap/SplitText'],
            vendor: ['glightbox']
          }
        }
      },
    },
  });
  ```

  After making changes:
