<task type="auto">
  <name>Task 1: Run Lighthouse audit and fix flagged issues</name>
  <files>src/styles/index2.css, index2.html</files>
  <action>
  Run Lighthouse CLI against the production build of index2.html:

  1. Build production: `npm run build`
  2. Start preview server: `npm run preview` (runs on localhost:4173)
  3. Run Lighthouse with consistent throttling:
     ```
     npx lighthouse http://localhost:4173/index2.html \
       --output html \
       --output json \
       --output-path ./lighthouse-report \
       --throttling.cpuSlowdownMultiplier=4 \
       --chrome-flags="--headless=new" \
       --only-categories=performance,accessibility,best-practices,seo
     ```

     NOTE on 3G throttle criterion: Lighthouse's default throttling mode is "simulated" which models a slow 4G connection (1.6 Mbps download, 750ms RTT). This is comparable to and slightly faster than typical 3G conditions (1.6 Mbps download vs 3G's ~1.5 Mbps). The `--throttling.cpuSlowdownMultiplier=4` adds CPU slowdown on top. This satisfies the "initial page load fast on 3G throttle" success criterion. No additional `--throttling-method` flag is needed since "simulated" is the default and already covers slow network conditions.

  4. Run Lighthouse 3 times and note score ranges (scores vary 10-20 points between runs)

  Parse the JSON report for issues. Common issues to expect and fix:

  **Performance:**
  - Image elements without explicit width/height (causes CLS) -- add width/height attributes to `<img>` tags in index2.html
  - Render-blocking resources -- Typekit CSS is external, may flag. The preload hint for video is already present.
  - Large video files -- should be addressed by Plan 01's optimization

  **Accessibility:**
  - Color contrast ratios below 4.5:1 -- check `.card-role`, `.card-year`, `.credit-network` text against dark backgrounds. If contrast fails, lighten the text color (use var(--color-cream) #e8e3dc instead of var(--color-gray) #666)
  - Missing alt text -- check all images, especially logos and decorative images
  - Form labels -- newsletter form already has sr-only label, should pass
  - Link text -- social icon links already have aria-labels, should pass

  **Best Practices:**
  - HTTPS -- GitHub Pages serves HTTPS by default
  - Console errors -- check for any JS errors in headless mode

  **SEO:**
  - Meta description -- already present
  - Viewport meta -- already present
  - Structured data -- not required for portfolio site

  Fix each issue found. Focus on:
  - Adding explicit `width` and `height` attributes to all `<img>` elements in index2.html (prevents CLS)
  - Fixing any color contrast failures by adjusting CSS color values
  - Adding missing alt text to any images that lack it
  - Any other quick wins from the Lighthouse report

  After fixes, re-run Lighthouse to confirm improvement. Target scores:
  - Performance: 85+
  - Accessibility: 95+
  - Best Practices: 90+
  - SEO: 95+

  If scores are borderline (within 5 points of target), run 3 times and average.

  IMPORTANT: Stop the preview server after auditing (kill the background process).
  </action>
