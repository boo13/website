<objective>
Optimize all video assets using FFmpeg VP9 two-pass encoding to reduce total video size from 42MB to under 25MB (40-50% reduction).

Purpose: Videos are the largest assets on the site. GitHub Pages does not support Git LFS, so aggressive compression is the only path to fast load times. The hero montage alone is 18MB (LandingPageMontage_Test_v01.webm) and the primary hero video is 6.3MB.

Output: Optimized video files in public/video/ and a reusable encoding script in scripts/.
</objective>

  ```bash
  grep -r "Capsized.10secReel.v01_1920x1080.webm" --include="*.html" --include="*.js" .
  ```

  Print each result to stdout with a clear "USED" or "UNUSED" label per file. Expected results:
  - `LandingPageMontagev04.2.webm` (6.3MB) -- hero video in index2.html, preloaded -- USED
  - `Cowboy.War.10secReel.v01_1920x1080.webm` (1.6MB) -- gallery card lightbox + hover preview -- USED
  - `LandingPageMontage_Test_v01.webm` (18MB) -- likely a test file, may be UNUSED
  - Others -- verify with grep output

  Then create `scripts/optimize-videos.sh` -- a bash script that:
  1. Takes input file, output file, and optional CRF value (default 31)
  2. Uses two-pass VP9 encoding: `ffmpeg -i "$INPUT" -c:v libvpx-vp9 -b:v 0 -crf $CRF -pass 1 -an -f null /dev/null && ffmpeg -i "$INPUT" -c:v libvpx-vp9 -b:v 0 -crf $CRF -pass 2 -c:a libopus -b:a 128k "$OUTPUT"`
  3. Cleans up pass log files after encoding
  4. Has a `--batch` mode that processes all videos in a directory with preset CRF values:
     - Hero videos (filenames containing "LandingPage"): CRF 28
     - Gallery preview videos (filenames containing "Reel"): CRF 33
  5. Reports before/after sizes for each file
  6. Make the script executable with `chmod +x`

  Document the grep findings in a header comment block at the top of the script, listing each video file as "USED by [file:line]" or "UNUSED -- candidate for deletion". Also print the full summary to stdout when the script is created.
  </action>
  <verify>

  <done>Reusable encoding script exists, unused videos identified and documented in script header comments and printed to stdout</done>
