  <name>Task 1: Create FFmpeg optimization script</name>
  <files>scripts/optimize-videos.sh</files>
  <action>
  Create `scripts/optimize-videos.sh` -- a bash script that:
  1. Takes input file, output file, and optional CRF value (default 31)
  2. Uses two-pass VP9 encoding: `ffmpeg -i "$INPUT" -c:v libvpx-vp9 -b:v 0 -crf $CRF -pass 1 -an -f null /dev/null && ffmpeg -i "$INPUT" -c:v libvpx-vp9 -b:v 0 -crf $CRF -pass 2 -c:a libopus -b:a 128k "$OUTPUT"`
  3. Cleans up pass log files after encoding
  4. Has a `--batch` mode that processes all .webm files in a directory with preset CRF values:
     - Hero videos (filenames containing "LandingPage"): CRF 28
     - Gallery preview videos (filenames containing "Reel" or "Spotlight"): CRF 33
  5. Reports before/after sizes for each file
  6. Make the script executable with `chmod +x`

  Add a header comment documenting:
  - The 4 used videos (served from R2):
    - LandingPageMontagev04.2.webm (6.3MB) — hero video
    - LandingPageMontagev05_9x16.webm (2.4MB) — mobile hero

  - R2 bucket: portfolio-assets
  - CDN base: https://pub-722bb50dc4774406afca73534059fdd8.r2.dev
  - Upload command: `npx wrangler r2 object put portfolio-assets/video/FILENAME --file public/video/FILENAME --content-type video/webm --remote`
