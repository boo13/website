  <name>Task 1: Install GLightbox and create video-lightbox component</name>
  <files>
    package.json
    src/components/video-lightbox.js
    src/styles/video-lightbox.css
  </files>
  <action>
    1. Install GLightbox:
       ```
       npm install glightbox
       ```

    2. Create `src/components/video-lightbox.js`:
       - Import GLightbox and its CSS (`glightbox/dist/css/glightbox.min.css`)
       - Export `initVideoLightbox()` function that:
         - Initializes GLightbox with selector `.glightbox-video` (elements with this class trigger lightbox)
         - Config: `touchNavigation: true`, `loop: false`, `autoplayVideos: true`, `closeButton: true`, `closeOnOutsideClick: true`, `keyboardNavigation: true`
         - Arrow keys cycle through all gallery items (gallery-style, per user decision)
         - Returns cleanup function that calls `lightbox.destroy()`
       - Follow existing component pattern (see `src/components/custom-cursor.js` for reference)
       - Do NOT use Plyr or any third-party video player — use native HTML5 video controls

    3. Create `src/styles/video-lightbox.css`:
       - Override GLightbox default styles to match dark theme:
         - Backdrop: `rgba(10, 10, 10, 0.95)` (matches --color-nearblack)
         - Close button: `var(--color-offwhite)` with hover opacity
         - Navigation arrows: `var(--color-offwhite)` with hover opacity
         - Video container: remove any default borders/shadows that clash with dark theme
       - Ensure z-index is high enough (GLightbox defaults to 100001/100002, which is above the existing z-index:100 gallery progress and z-index:1000 cursor-preview)
       - Override any light-colored text/backgrounds from GLightbox defaults
  </action>
  <verify>
    - `npm ls glightbox` shows glightbox installed
    - `src/components/video-lightbox.js` exists and exports `initVideoLightbox`
    - `src/styles/video-lightbox.css` exists with dark theme overrides
    - `npm run build` succeeds (Vite can resolve GLightbox import)
  </verify>
  <done>GLightbox installed as dependency, video-lightbox component created with gallery navigation config, dark theme CSS overrides written. Build passes.</done>
</task>
