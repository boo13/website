The new section HTML:

```html
<!-- =====================================================
     SECTION: CALL TO ACTION
     Newsletter signup + contact link
====================================================== -->
<section id="cta" class="cta-section">
    <div class="container">
        <div class="cta-content">
            <h2 class="cta-heading">Stay in the loop</h2>
            <p class="cta-subtext">Get occasional updates on new projects and productions.</p>

            <form
                action="https://buttondown.com/api/emails/embed-subscribe/randycounsman"
                method="post"
                class="newsletter-form"
                target="_blank"
            >
                <div class="newsletter-input-group">
                    <label for="newsletter-email" class="sr-only">Email address</label>
                    <input
                        type="email"
                        name="email"
                        id="newsletter-email"
                        placeholder="your@email.com"
                        required
                        autocomplete="email"
                    >
                    <input type="hidden" name="embed" value="1">
                    <button type="submit" class="newsletter-submit">Subscribe</button>
                </div>
            </form>

            <div class="cta-divider"></div>

            <a href="contact.html" class="cta-contact-btn">
                Get in Touch
                <svg width="16" height="16" viewBox="0 0 16 16" fill="none">
                    <path d="M3 13L13 3M13 3H5M13 3V11" stroke="currentColor" stroke-width="2" stroke-linecap="round"/>
                </svg>
            </a>
        </div>
    </div>
</section>
```

Notes:
- Buttondown username is "randycounsman" as placeholder (user can change later by updating the form action URL)
- `target="_blank"` on the form so Buttondown's confirmation page opens in a new tab
- `sr-only` class for accessible label (hidden visually but available to screen readers)
- Uses the same arrow SVG icon pattern already used in the contact and about sections
- The `<input type="hidden" name="embed" value="1">` tells Buttondown this is an embedded form
- DO NOT add JavaScript for the form -- standard HTML form POST is sufficient for rough layout
- DO NOT add loading states, success messages, or error handling (deferred to polish phases)
